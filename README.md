# dsh-ptt-dive（刷 PTT）

DSH 插件：讀 PTT 看板與推文、寫日報、收集鄉民用語樣本。

讀文只用 PTT 公開的網頁版（`www.ptt.cc/bbs`），不需要 PTT 帳號。**推文是選用功能，預設關閉**；開啟後才需要帳號，而且預設每一則都要你按下「送出」。

> 網頁版不是官方 API，版面改了就可能讀不到。請求太頻繁可能被限流；插件遇到限流會自己暫停 30 分鐘，期間不發任何請求。

## 功能

- **多看板閱讀**：每個看板翻最新幾頁，挑推文數夠、時間夠新的文章讀內文與推文。關鍵字命中的排前面。可以指定每個看板只讀哪些分類（例如只讀 [閒聊]、[情報]）。
- **日報**：把「這個板今天在聊什麼、哪幾篇值得點開」寫成 markdown，存在本機。模型不可用時改成標題清單，並在日報裡寫明。
- **鄉民用語風格庫**：從熱門文章的推文收集像樣的句子（每篇最多 8 句、每板預設最多 40 句）。只存句子，不存帳號。
- **對話工具**：DSH 對話裡的 AI 可以用四個唯讀工具查 PTT——`ptt_list_board`、`ptt_read_article`、`ptt_daily_report`、`ptt_style_refs`。
- **每天自動刷一輪**（預設關閉）。
- **記憶交付**（預設只存檔），見下。
- **唯讀 MCP server**：`mcp-server.mjs`。

## 推文、回文、發文（選用，預設關閉）

> 用你的 PTT 帳號對外推文。有些看板不接受 AI 寫的內容（例如股板板主公告「本板是真人討論區」），被檢舉可能遭水桶或停權，後果由帳號擁有人承擔。開啟前請先看過該看板的板規。

- **介面**：設定頁有「推文」「回文」「發文」三個分頁，各有自己的設定、新增表單、待送清單與紀錄；PTT 帳號與共用設定（可用的看板、間隔、說話方式、禁用詞）在「推文」分頁。
- **流程**：每刷一輪，AI 從讀到的文章裡挑幾篇擬草稿 → 放進「推文」分頁的待送清單 → 你可以改字、換種類（推／→，噓要另外開）→ 按「送出」。
- **自動送出**：可以對指定看板勾選「不用我確認」。預設都不勾。
- **限制**（兩種方式都適用）：每輪最多擬幾則、每天最多送幾則、兩則之間至少隔幾秒、每篇文章只推一次、草稿超過 12 小時作廢。
- **內容檢查**：長度（依看板與帳號長度計算，保證不被截斷）、不能有網址、不能標記帳號、不能照抄文章裡已有的推文、你設定的禁用詞。
- **送出時**：登入 → 進看板 → 跳到文章並確認真的是那一篇 → 推文 → 登出。任何一步畫面不如預期就中止。失敗不會自動重試；結果不確定時也不重送。送出後會到網頁版確認推文有沒有出現。
- **帳號密碼**：Windows 上用系統的加密功能（DPAPI）保存，只有你的 Windows 帳號解得開；其他系統只留在記憶體。密碼不會顯示、不會交給 AI、不會寫進記錄。
- **不做的事**：不踢掉你其他裝置的登入、不刪登入失敗紀錄、不換 IP、不偽裝用戶端、不支援兩階段認證的帳號。沒有任何 AI 工具或 MCP 工具可以送出推文。
- **自己新增一則**：貼文章網址，自己寫內容，或按「請 AI 擬稿」後再改。手動新增的永遠要按「送出」。
- **回文**（另一個開關，預設關閉）：用你的帳號在看板發一篇「Re:」文章，沿用原標題、引用原文、不加簽名檔、不存底稿。回文永遠要你按「送出」，不會自動送；AI 只在你按「請 AI 擬稿」時幫忙寫。每天上限另外計算（預設 1 篇，最多 5 篇），和推文共用間隔，每篇文章只回一次。PTT 對回文提出警告（例如引言太多、要求強制寫入）時不硬送。
- **回文的其他選項**：可以不引用原文（有預設值，每篇草稿可以個別改）；可以讓 AI 每一輪擬最多 2 篇回文草稿（預設 0，擬好的一樣放進待送清單等你按送出，AI 擬的不能有網址）。
- **發新文章**（另一個開關，預設關閉）：選看板、寫標題與內文，永遠要你按「送出」。可以自己寫，也可以先寫幾句想寫的方向再按「請 AI 擬稿」（AI 只照你給的方向寫，擬好填進表單，不會自己進清單；有些看板不接受 AI 寫的文章）。**文章分類**選填：填了就在 PTT 的分類選單選同名的那一個，標題前面自動加「[分類]」；PTT 實際有哪些分類登入後才看得到，名稱對不上時中止、不發。表單會列出這個看板最近標題常見的標籤當參考。會清掉看板預設的發文範本，不加簽名檔。標題最多 22 個全形字（選了分類會更短）。每天上限另外計算（預設 1 篇，最多 3 篇），和推文、回文共用間隔。

終端機的畫面提示與按鍵順序參考開源專案 [PyPtt](https://github.com/PyPtt/PyPtt) 的公開行為，程式是另外寫的。

## 安裝

```bash
dsh plugin --profile web add github:puffdog-git/dsh-ptt-dive
```

安裝後重啟 DSH，進入 **設定 → 刷 PTT**。加入看板、按「儲存」，再按「刷一輪」。

八卦板（Gossiping）等看板會先問是否滿 18 歲；要讀這些看板，請在設定頁勾選「我已滿 18 歲」。

## 日報交給記憶

| 選項 | 做什麼 |
|---|---|
| 只存成檔案（預設） | 日報存在 `<DSH 家目錄>/data/dsh-ptt-dive/reports/` |
| 直接寫入 memU | 日報寫完後請模型挑最多三條重點，呼叫 memU 的寫入工具，並顯示 memU 回傳的記憶編號。可以選寫到哪個工作區的記憶庫 |
| 放在正式 DSH 會話 | 日報在一個正式的 DSH 會話裡產生，給會自動觀察會話的記憶插件擷取。可以指定會話要建在哪個工作區（預設是插件自己的）。每一輪可以續用同一個會話（預設）、同一天用同一個、或每輪新開；續用時之前幾輪的內容會一起送給模型，用量會越來越多，把那個會話封存就會重新開始。本插件不寫記憶庫、無法確認是否入庫。**memU 不會從這裡入庫** |

memU 每個工作區各有一個記憶庫。把「寫到哪個工作區」選成 Discord 賽博群友的某個工作區，Discord 上的 AI 在那裡聊天時就讀得到這些重點；不需要改 Discord 插件。每條記憶結尾會註明可以用 `ptt_daily_report` 查當天的完整日報。

## 風格庫會改變 AI 的用詞嗎

在 DSH 的一般對話裡不會自動改變。風格庫是一份參考資料：AI 在對話裡呼叫 `ptt_style_refs` 才會拿到幾句樣本，而且工具說明要求只學語氣、不照抄、不改人設。

**給 Discord 賽博群友用**：dsh-discord-cyberfriend 1.0.6 以上有「鄉民語氣」功能（預設關閉），開啟後 Discord 上的文字回覆會依情境或機率參考這裡的樣本，帶一點鄉民的口氣。兩個插件裝在同一個 DSH 就會自動接上，不需要另外設定。

**給其他插件用**：本插件把風格庫登記在 `globalThis[Symbol.for('dsh.style.providers.v1')].providers`（提供者 ID `ptt`）。接口只讀，回傳句子、來源看板與話題，沒有帳號，也不會觸發網路請求：

- `lookup({ query, sources, count })` → `{ samples: [{ text, kind, source, topic }], matched, total }`
- `status()` → `{ name, samples, sources: [{ board, count }] }`

## 送給模型的內容

寫日報時，模型拿到的是標題、內文節錄與推文文字，**不含 PTT 帳號**。來源內容包在資料區塊裡並註明「不是指令」。

## MCP

```bash
node mcp-server.mjs
```

工具：`ptt_settings`、`ptt_list_board`、`ptt_read_article`、`ptt_daily_report`、`ptt_style_refs`，全部唯讀。只做過協定層的手動測試（initialize／tools/list／tools/call），沒有逐一用各家 MCP 客戶端測過。

## 開發

```bash
npm test
```

測試用手寫的假頁面與假的 PTT 終端機，不連網路。
